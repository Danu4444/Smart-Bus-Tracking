# Smart Bus Tracking and Prediction System

## Overview

Smart Bus Tracking and Prediction System is a web-based application designed to provide real-time bus tracking and estimated arrival time (ETA) prediction. The system helps passengers monitor bus locations, receive travel updates, and communicate with drivers, while administrators manage buses, drivers, and trips efficiently.

## Features

* Real-time bus tracking using GPS
* Estimated Time of Arrival (ETA) prediction
* Passenger, Driver, and Admin authentication
* Live trip status monitoring
* Passenger–Driver chat system
* Bus and driver management
* Notifications and alerts
* Trip monitoring and reporting

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Move the project folder to:

   ```
   xampp/htdocs/
   ```

3. Start Apache and MySQL using XAMPP.

4. Import the database file into MySQL.

5. Open the application in a browser.
